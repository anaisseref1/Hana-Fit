# Hana-Fit# 🌸 Hana Fit

Hana Fit est une application de suivi santé, nutrition et bien-être développée progressivement.

## Objectif

Créer une application moderne, élégante et intelligente permettant de suivre :

- 🍽️ Nutrition
- 💪 Entraînement
- 🌿 Bien-être
- 📈 Progression
- 📅 Programmes alimentaires
- 🐈 Assistant intelligent NEHA
